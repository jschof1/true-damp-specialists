# Prompt: GHL Review Campaign

Use the `gohighlevel-api` skill where credentials/scopes allow.

Create or prepare a review request campaign using GHL contacts/workflows.

Rules:

- Do not message contacts without approval.
- Segment only real recent happy customers or client-approved contact lists.
- Draft SMS/email copy that asks for honest feedback, not fake or scripted reviews.
- If a workflow ID exists in `client.json`, prepare approved enrollments.
- Log all planned or completed actions.
